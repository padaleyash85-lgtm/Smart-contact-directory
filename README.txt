SMART CONTACT DIRECTORY WEBSITE — DSA MICRO PROJECT

How to run:
1. Download and extract Smart_Contact_Directory_Website.zip.
2. Open index.html in Chrome or another modern browser.
3. Add a contact, or tap Load demo to add sample contacts.
4. Search an exact full name. Search ignores uppercase/lowercase.

Files:
- index.html contains the website layout, styling, and JavaScript logic in one easy-to-open file.

DSA:
- Array of contact objects stores records.
- Bubble sort alphabetically sorts names.
- Iterative binary search locates a name in O(log n) time after sorting.
- Bubble sort is O(n^2) average/worst case, with an O(n) best case when already sorted.
- localStorage keeps contacts in the same browser on the same device; it is not cloud sync.

For your report/viva, explain that binary search only works correctly on sorted data.
Do not store private contact information on a shared device.
